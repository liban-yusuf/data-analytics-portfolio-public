## How to review a project

1. Read the business question and data description in the project's README.
2. Run the included script and any tests using the documented commands.
3. Compare outputs with the stated results and inspect the assumptions.
4. Explain what the results mean, and what the synthetic data cannot establish.

## Portfolio principles

- Synthetic examples are clearly identified and are not represented as real bank or client data.
- A documented design is not a deployed solution.
- Certifications, live dashboards and Fabric execution evidence are listed only after completion.
- The code and underlying analysis are the evidence; no unverified performance claims are made.
